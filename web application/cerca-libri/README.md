# Cerca libri (Angular + Google Books API)

```bash
npm i -g @angular/cli
ng new cerca-libri --style=css --ssr=false --routing=false
cd cerca-libri
# sostituisci questi file con quelli forniti:
#   src/app/app.ts
#   src/app/app.config.ts
#   src/styles.css
ng serve
```
Apri http://localhost:4200. Richiede Angular 20 (nome classe `App`, file `app.ts`).
Per Angular 17–19: rinomina `app.ts` in `app.component.ts`, la classe in `AppComponent` e aggiorna `main.ts`.
